Prompt for DriverSafe — Main Dashboard (/dashboard)
Create a full dark-theme dashboard page for "DriverSafe" — 
an AI-powered unsupervised drowsiness detection system.
Built with Next.js 14 App Router, Tailwind CSS, Shadcn/UI, TypeScript.

═══════════════════════════════════════════
TECH STACK
═══════════════════════════════════════════
- Next.js 14 (App Router)
- Tailwind CSS
- Shadcn/UI components
- TypeScript
- Recharts (for all charts)
- Lucide React (for all icons)
- WebSocket (for live feed simulation)

IMPORTANT NOTES
═══════════════════════════════════════════
- NO light mode, dark only
- NO unnecessary animations 
  (keep UI clean and fast)
- ALL data is static/mock 
  (no API calls needed yet)
- TypeScript strict mode
- Mobile responsive not required 
  (desktop dashboard only)
- Use "use client" on all 
  interactive components
- Recharts must have explicit 
  width/height or use ResponsiveContainer
